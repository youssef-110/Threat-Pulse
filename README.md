# ThreatPulse

A 3D globe that visualizes simulated global cyber attacks, in a single HTML page.
Attack arcs fly between countries on a rotating Three.js globe, with a live-updating
feed and counters alongside.

The attack data is simulated in the browser; no real threat feed is called.

## Run

Open `index.html` in a browser, or serve the folder with any static host. It loads
Three.js and GSAP from cdnjs and country outlines from Natural Earth.
